# 周期任务推荐海域

| 任务 | 要求摘要 | 推荐 |
|---|---|---|
| Bd4 敌空母 3 | 击沉空母 3 | 2-1；也可随其他周/月常完成 |
| Bd5/Bd6 补给舰 | 击沉补给舰 3/5 | 2-2；可叠加ろ号、东方等 |
| Bd7 南西日常 | 2-1～2-5 Boss 胜利 5 | 优先有限时掉落的图；无目标时 2-1 可叠加い号 |
| Bd8 敌潜艇 6 | 击沉潜艇 6 | 1-5，4DD/DE |
| Bw1 あ号 | 出击/Boss/S胜累计 | 随其他任务；缺次数可 1-1 刷闪 |
| Bw2 い号 | 击沉空母 20 | 2-1，5 圈可叠加 Bd7 |
| Bw3/Bw4 补给舰 20/50 | 击沉补给舰 | 2-2，或随 4-2 东方任务 |
| Bw5 海上护卫 | 击沉潜艇 15 | 1-5，可叠加 Bd8/Bw10/Bm5 |
| Bw6 东方舰队 | 4-1～4-5 胜利 12 | 常用 4-4；需要补给舰进度时 4-2 |
| Bw7 北方舰队 | 3-3～3-5 胜利 5 | 常用 3-3；也可按掉落选择 3-4/3-5 |
| Bw8 东方中枢 | 4-4 胜利 | 沿用 Bw6 的 4-4 编成 |
| Bw9 珊瑚制空 | 5-2 S胜 2 | 5-2；可用翔鹤+瑞鹤路线或常规空母战舰队 |
| Bw10 输送路安全 | 1-5 A胜 3 | 1-5，4DD/DE |
| Bm1 第五战队 | 2-5 S胜 | 妙高+那智+羽黑为核心，按 2-5 任务配置 |
| Bm2 潜水舰队 | 6-1 S胜 3 | 1AS+1CL+4SS，或 1CV+1CL+1CLT/AV+3SS |
| Bm3 水雷南西 | 1-4 S胜 | 2CL（旗舰）+4DD |
| Bm4 水上打击 | 5-1 S胜 | 指定战舰系 3+1CL；余位按地图配置 |
| Bm5 海上护卫强化 | 1-5 A胜 10 | 1-5，4DD/DE |
| Bm6 空母机动西进 | 4-2 S胜 | 2CV系+2DD为任务核心，可叠加 Bw6 |
| Bm7 水上反击 | 2-5 S胜 | DD旗舰、4DD+1CL+1CA，不能用 CAV |
| Bm8 兵站线 | 1-2/1-3/1-4/2-1 各 S | 以 1CL/轻母系+3DD/DE 为核心，逐图读取配置 |
| Bq1 冲之岛迎击 | 2-4 S胜 2 | 2-4，可叠加 Bq2 |
| Bq2 Z作战前段 | 2-4/6-1/6-3 A，6-4 S | 分图执行；2-4 与 Bq1、6-1 与 Bm2 合做 |

表中仅用于选择海域和叠任务。准确编成、路线、制空和索敌必须再读 `fleet-builder/refs/quest-sortie-configs.md` 与对应地图模块。

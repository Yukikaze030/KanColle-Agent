# Event Guide Skill

**时期：只查二期活动。** 一期活动/旧锁船/旧路线一律忽略。

## 触发

活动 / E 地图 / 甲乙丙 / 锁船 / 活动配队。

## 工作流

1. **必须在线确认当前活动**
   - kcwiki-researcher（禁止只靠模型内部知识；必须标明 era=二期）
2. **关卡信息**
   - 分图查询：路线、带路、Boss、奖励、锁船
3. **玩家化（可选）**
   - Poi 舰娘库存 / 装备 / 资源 / 桶
   - 判断甲/乙/丙可行性
4. **配队**
   - 结合 fleet-builder 原则

## 输出模板

```
当前活动：<名称>（来源与日期）
E2 甲：
  路线：…
  编成建议：…
  你能否打甲：能/勉强/建议乙（依据：舰娘/装备/桶）
  风险：…
```

## 硬规则

- 活动攻略以 Wiki 为主，Data MCP 只补舰娘装备静态数据
- 多源冲突时写出差异，不静默选边
- 锁船建议必须考虑玩家后续图的需求
- 不确定时明确说「需以最新 Wiki 为准」

# 活动攻略

遵循已加载的 `kancolle-main` 公共约束；若未加载，先加载。

1. 必须委派 researcher 在线确认当前活动及目标关卡/难度，返回来源与日期。
2. 按目标分图查路线、带路、Boss、奖励与锁船；锁船决策还须考虑后续图需求。
3. 仅在玩家化建议时查询 Poi 舰娘、装备、资源与桶；需要具体配队再加载 `fleet-builder`。
4. 输出活动名称、目标难度攻略与风险；判断能否挑战某难度须给账号依据。

攻略以 Wiki 为主，Data 只补静态事实。来源冲突列出差异，未确定信息明确标注需最新 Wiki 核实。

## 使用方式

1. **fleet-builder**：先查目标图带路（原帖分图或 kcwiki），再用 Poi 舰娘/装备落地编成  
2. **quest-planner**：任务卡关时用上表定位推荐图，再 Data `kc_quest_graph` + Poi 进度  
3. 改造名（矢矧改二乙、北上改三、山城改二补等）→ **Data MCP 核实**后再写建议  
4. 详细节点带路/制空表：打开原帖或读 `raw` 对应段落，勿在 skill 正文粘贴全文

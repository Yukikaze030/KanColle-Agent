# 4-4 カスガダマ島

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454454163（NGA「带路条件」弹窗）

- 万能的地图，敌方有空母、有补给、有潜艇、能做东方、能练几乎所有的舰种
- 还能3CVL+3DE或2DE1AO走A-E-C偷油

- 各种攻略路线以及带路：
- A-E-I-K路线：
- 唯一推荐路线，但有3种不同的带路体系
- 2DD/DE + 1CL/CA/CAV + 2CV/CVB + 1个CV/CVB以外的任意舰种
- 2DD/DE + 1CL+ 3个CV/CVB以外的任意舰种
- 2DD/DE + 2CA/CAV + 2个任意舰种
- 正常攻略任选一种就可以，注意如果只带1CV/CVB，就必须要用2CA/CAV带路
- 由于敌方道中有潜艇，boss点随机刷潜艇，在前期CL、DD无法先制对潜的时候，可以带一个DE对潜。
- 不过要注意DE本身比较脆容易被敌方小船炮击大破，需要配合较高的开幕输出清小船才比较稳(被敌方大船炮击更容易出中破保护是DE的优势)


| 路线 | 编成要求 | 备注 |
|------|----------|------|
| A-E-I-K | 2DD/DE+1CL/CA/CAV+2CV/CVB+1个CV/CVB以外的任意舰种 | 带路1 |
| A-E-I-K | 2DD/DE+1CL+3个CV/CVB以外的任意舰种 | 带路2 |
| A-E-I-K | 2DD/DE+2CA/CAV+2个任意舰种 | 带路3 |
| A-E-C 偷油 | 3CVL+3DE 或 2DE+1AO | 捞油 |

- 唯一推荐路线 A-E-I-K；注意只带1CV/CVB时必须用2CA/CAV带路
- 道中有潜艇，boss随机刷潜艇；前期CL/DD无法先制对潜时可带DE
- DE脆需高开幕清小船；被大船炮击更容易中破保护是DE优势

## 推荐编成

### 萌新推图（A-E-I-K）

- 制空：K点 144空确
- 索敌：无要求
- 分析：符合任一带路即可；可将1个DD换DE先制反潜；前期开幕弱不适合带2个DE；舰队成长后可换轻型队伍减耗

### 東方周常

- 制空：K点 144空确
- 需求：夕张改二特/阿武隈改二；海防舰；护卫空母
- 分析：体感各方面比4-2优秀；CVE尽量带有击坠回避攻击机省铝；DE易先制对潜修理时间低；未改DE血量完美100%击沉保护

## Boss要点

- K点 144空确
- 道中无空袭，DE不比DD多提高劝退率

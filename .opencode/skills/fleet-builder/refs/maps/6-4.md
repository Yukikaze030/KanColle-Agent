# 6-4 中部北海域ピーコック島沖

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 概要

两个出发点，两条风格迥异的攻略路线，汇聚到 1~2 水上舰 + 3~5 陆基的 Boss 点。空袭点消耗 4% 油 8% 弹，非最短路线容易导致 Boss 输出大幅下降。建议练对陆船（满潮、霞、伊势改二、夕张改二特、最上改二特）、清奖励对陆装任务、改修对陆装、开发 4 陆航、清开放陆航任务。

## 陆航

- 开放 6 图陆航需完成 F43「中部海域'基地航空隊'展開！」；每队消耗一个設営隊
- 設営隊可从 B80/B81/Cy6/F106 任务获取；任务给的够用不必氪金
- 6-4 可出击一队陆航；多余設営隊可投入强化整备（加快疲劳恢复）
- 陆航对水上舰算雷装，对陆基算爆装；面板命中大幅提高命中率
- 建议打 6-4 前先凑齐 4 架一式或更强陆攻
- **陆航携带任意喷气机可无视航程直达 Boss（6-4 独有，不适用其它图，也不能直达道中点）**
- 当前版本 Boss 不缺输出，一般陆航建议都放到 C 点提高道中通过率

## Boss 要点

Boss 为 離島棲姫 + 炮台小鬼 + 集積地棲姫(DJ) + 輸送ワ級 等混合。

| 目标 | 要点 |
|------|------|
| 離島 | 血量/装甲高，部分对陆装补正低（如三式弹）；陆航炸道中时队伍配 3 个夜战二连火力达阈值(360)的单位 |
| DJ（集积地） | 薄皮大馅首要迫害对象；大多数对陆装有阈值后补正；陆航炸道中配 3 个一拳单位，炸 Boss 可降到 1~2 个 |
| 炮台 | 对空很高导致老司机跳海；阈值 220 后秒杀率高很多；全员尽量能打炮台，尽量昼战解决，拖到夜战会吸火力且夜战二连恐怖 |
| 金皮补给 | Boss 点最硬，会吸大量对陆火力；靠长陆胸热/复数开幕雷/陆航解决 |
| 撸爷（C 点） | 一炮一个小朋友；6 号位混轻母至少要拿空均；陆航必须去炸 C（当前版本推荐） |

站位：1/2 号位对 C 撸爷有输出的高火力单位；3 号位起对炮台/DJ 输出；末尾对离岛二连输出单位。

## 制空

- 高速流：至少一个水战；或 F 点 123 空优
- 低速流：至少一个水战（秋津洲可背）
- 陆航目标 C：44 空优或 87 空确，航程 3；目标 N：神风，航程 5
- 索敌：无要求

## 推荐编成

### 高速流（推荐）

- 带路：CL 旗舰+3DD+1BB 系+1CL 系/CA 系/AV…，高速
- 阵型：B 单纵 → D 轮型 → C 单纵 → F 轮型 → N 单纵
- 成员：旗舰 CL 矢矧改二乙/夕张改二特 > 其他；BB 大和改二/伊势改二 > 其他高速 BB；对陆 DD 优先可装登陆艇/内火 + 孔可装电探/钢板
- 特点：道中通过率高、斩杀率高、不需要秋津洲；个别低速船需提速
- 分析：出门水雷弱，不需脆皮秋津洲；当前版本对陆输出上限高，陆航炸 Boss 收益小推荐炸 C；开幕雷作用极大先手清小船；最上改二特比陆奥更强更全能
- 陆航：目标 C，制空 44 空优或 87 空确，航程 3

### 低速流

- 带路：长门改二+陆奥改二+秋津洲+2DD+1CL/CAV
- 阵型：A 单纵 → D 轮型 → C 单纵 → F 轮型 → N 单纵
- 成员：必备秋津洲；BB 长陆 > 其他；带路巡洋最上改二特 > 其他；DD 同高速流
- 特点：通过率比高速流低；Big7 特殊攻击斩杀率略高；必须有秋津洲；不需要提速
- 分析：Boss 不缺输出可秋津洲旗舰保护，一路单纵不胸热；长陆带徹甲弹提高炮台满血击杀率；DD 优先配一拳
- 胸热变体：Boss 梯形胸热，本版本仅略微提升 S 胜率；秋津洲至少背 2 水战+孔喷二，DD 全力对空

### 萌新高速立体流

- 成员：夕张改二特 + 伊势改二 + 最上改二特 + 满潮改二 + 霞改二 + 滨风乙改
- 带路：CL 旗舰+3DD+1BB 系+1CL 系/CA 系/AV…，高速
- 陆航：对陆装达标炸 C，否则炸 N；C 航程 3，N 航程 5
- 分析：对陆装需求不高、调整空间大；伊势改二配双舰爆打立体攻击，舰爆对离岛和炮台补正高；内火强烈建议改修 max，大发至少 +6；战车+内火改修低时一拳应再加一枚火箭弹

## 对陆配装要点

### DJ 一拳

- 标准：[大発動艇(八九式中戦車&陸戦隊) 战车] + [特二式内火艇 内火] + [WG42]
- 高配：[战车+max] + [内火+max]（可弃 WG 换电探提高命中）
- 6-4 DJ：DD 满弹进 Boss 需 730 火力稳定击杀
- 下位替换：战车→登陆艇→火箭弹→迫击炮；内火→火箭弹/迫击炮/登陆艇（注意登陆艇改修补正取平均）
- 同名火箭弹/迫击炮第二件补正比第一件高；多个一拳输出尽量平均

### 离岛

- 昼战仅 Big7 特殊攻击可一炮击杀
- 夜战需二连（带两门炮）
- DD 第三件：M4A1 DD > 士魂队 > 高改修内火；或塔什干带两个同名火箭弹
- CL 4 格船/由良可装副炮；夕张改二特、由良可兼一拳
- CA 用 CAV 三式弹+火箭弹或双火箭弹；单三式弹对离岛仅 1.75 倍很差
- BB 单三式弹没问题；伊势级改二双舰爆中破也能摸到阈值

### 炮台

- 阈值 220 后满血击杀率高很多；一般不专门优化配装，对空 DD 带一个火箭弹即可

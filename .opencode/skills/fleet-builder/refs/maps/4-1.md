# 4-1 ジャム島沖

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454453876（NGA「带路条件」弹窗）

- 敌方配置以小船为主，我方可以带一个BB/CV以大欺小
- 出门随机，走下路可以白嫖一些油
- E点有补给而且经验不低，不过会随机刷出撸爷，一般不会去那里做补给任务

- 各种攻略路线以及带路：
- A-B-D-H-J / C-F-D-H-J路线：
- 1CL+2DD+2CA/CAV+1BB/CV
- D点敌方水上水下混合，不过两方面都不是很强， 可以随意选一个阵型打，以对各阵型的特点有个粗略的了解
- 另外需要稍微防备一下门神的金莉莉
- 不太推荐走其他路线


| 路线 | 编成要求 | 备注 |
|------|----------|------|
| A-B-D-H-J / C-F-D-H-J | 1CL+2DD+2CA/CAV+1BB/CV | 唯一推荐路线 |

- 敌方以小船为主，可带1个BB/CV以大欺小
- 出门随机，走下路可白嫖油
- D点水上水下混合，可随意选阵型
- 门神有金莉莉需防备

## 推荐编成

### 萌新推图（A-B-D-H-J / C-F-D-H-J）

- 制空：J点 36空优 / 72空确
- 索敌：无要求
- 需求：瑞云
- 分析：大船只能带1个，优先BB（CV前期输出不足易吃闭幕雷）；制空靠满熟练瑞云；有水战更好

## Boss要点

- C-F-D-H-J 点击坠比 A-B 路线高
- J点 36空优 / 72空确

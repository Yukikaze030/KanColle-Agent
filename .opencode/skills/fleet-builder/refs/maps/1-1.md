# 1-1 鎮守府正面海域

> 二期 · 改造名须 Data MCP 核实

## 要点

- 罗盘随机，无法稳定进 Boss。
- 常用作刷闪图：不会先制对潜的船来这里；会先制对潜的去 1-5。
- 道中大破不要进击，有击沉风险。1-1 可道中夜战；其他图除捞船外避免道中夜战（弹药补正）。
- 阵型：对潜单横、对空轮型、夜战梯形、大船打小船复纵、其余单纵。

## 刷闪配置

- 目标船旗舰 + 狗粮 DD/SS 僚舰挡枪（无破狗粮单纵约 45% 挡枪）。
- 空母/水母：≥18 搭载塞彩云防喷铝，其余刷熟练度；僚舰可带不可开幕 SS 补刀。
- 中射程以上：2DD + 10 级以下 SS。
- 短射程：1DD + 1 不可开幕 SS（2DD 可能狗粮先手击沉导致刷闪失败）。
- 喷气机耗钢，刷熟练去 1-5 或 5-2。

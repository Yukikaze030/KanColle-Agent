# 地图文档标题规范

本目录中的正式地图文档仅指文件名匹配 `^[1-7]-[1-6]\.md$` 的文件。`_raw-post.txt`、`_routing*.json`、索引、规范和工具脚本不属于正式地图文档。

## 标题约定

- H1：`# [map:<map-id>] <map-id> <地图名>`，每份文档恰好一个，且 `<map-id>` 必须与文件名及 front matter 的 `map` 一致。
- H2：`## [module:<key>] <中文标题>`。机器只依赖方括号内的 key；中文标题用于阅读，不作为查询接口。
- H3 及以下：是所属 H2 模块内部的自由子节，可以保留路线、阶段、配队或任务分组的原始名称。
- module key 不随措辞变化，不复用、不翻译；新增顶级模块前须先更新本规范和校验脚本。

## 模块表与顺序

| key | 中文标题 | 必需 | 内容 |
|---|---|---:|---|
| `overview` | 地图信息 | 是 | 地图性质、阶段和总体提示 |
| `routing` | 带路条件 | 是 | 路线分歧、编成限制和路线内子节 |
| `enemy` | 敌方配置 | 是 | 节点敌舰及阵容 |
| `air-los` | 制空 / 索敌 | 是 | 制空状态、索敌阈值和搭载提示 |
| `bonus` | 海域倍卡 | 否 | 海域特效或倍卡；没有时不创建空模块 |
| `fleets` | 推荐编成 | 是 | 配队方案、战术、攻略流程和配装要点 |
| `quests` | 任务配置 | 是 | 任务要求与对应编成 |
| `notes` | 备注 | 是 | 数据时代、核实边界及补充说明 |

模块必须按表中顺序出现。每个 key 在单份地图文档中最多出现一次；除 `bonus` 外均须出现一次。

## 查询示例

- 定位地图：搜索 `^# \[map:5-6\]`。
- 定位所有编成模块：搜索 `^## \[module:fleets\]`。
- 提取单图模块：从目标 H2 读取到下一个 H2 或文件末尾。

运行 `./validate-maps.ps1` 可校验 front matter、地图标题、模块集合、模块顺序、重复 key 和空模块。

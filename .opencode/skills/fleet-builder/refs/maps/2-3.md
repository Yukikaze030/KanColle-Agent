# 2-3 東部オリョール海

> 二期 · 改造名须 Data MCP 核实

## 带路

出门随机 + Boss 前随机沟。**完全避沟：1CL+4DD 或 1CL+5CA**。

| 条件 | 作用 |
|------|------|
| BB 系+CV 系≤4 | 避大概率 J-L |
| ≥1 CV/AV/CL | 避 F-H |
| ≥1 CV 系 / AV / CL / CAV | 降 J-L |
| 1AV+2DD 或 1AS+2SS | 避 D-F |

- 前期重阵：1CV 系+1CAV+1AV+1CL+2BB/CV 系；输出向 4BB/CV 系+2CA/AV/CL
- 后期：1BB/CV+1CL+4DD 完全避沟
- 优质掉落（Johnston、神州丸、松轮）；日常南西可在此；6SS 耗低但沟率高

## 制空 / 索敌

N（Boss）司等≤89：77 优 / 153 确；≥90：36 均 / 81 优 / 162 确。索敌 0。安全搭载全程空确：4/3/2/2/2。

## 推荐编成

- **萌新推图**：重阵压沟；DD 喂满后可 1BB+2CV+1AV+2DD
- **掉捞**：沟率<1% 并降耗。双 CV；制空靠爆战/AV 水爆；CVL 低耗；2 搭载格只放中抗舰爆（彗星江草/岩井）；AV 1 水侦保接触；换 DD 为 CAV（沟×2.33）/CL（×3.33）/CV 系（×6.67）

# 6-1 中部海域哨戒線

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 带路条件

大鲸喷水图。想到达 Boss 需至少带 3 只 SS；I 点可捞 401 和马路油，Boss 点也有马路油。

| 路线 | 编成 | 备注 |
|------|------|------|
| C-F-G-H-K | 3SS+1BB/CV+1CL+1CLT/AV/CL/AS… | 输出最高；出门有撸爷；15% 概率沟 G-I |
| A-F-G-H-K | 大鲸(AS)+1CL+4SS | 绕过撸爷少一战；鲸脆且输出低，需大量高运 SS |
| A-D-F-G-H-K | 6SS | 道中三战敌方反潜强，Boss 输出不够，不推荐 |

- SS 喂满雷装能开幕雷即可，不必练到 50 改
- 带 CV+CLT 可走开幕流；伊势改二+日进可走炮击流
- 索敌：分歧点系数=4，主路线 ≥36；鲸鱼路线 ≥25

## 制空

| 路线 | 制空 |
|------|------|
| C-F-G-H-K | C 点 69 空确；Boss 放弃制空或 126 空优 |
| A-F-G-H-K | 不要 |

## 推荐编成

### 死库水即是正义（1-C-F-G-H-K）

- 需求：3SS
- 制空：C 点 69 空确，Boss 放弃
- 索敌：系数=4，≥36
- 分析：SS 不需高等级，雷装喂满；尽量提高开幕输出清小船反潜；飞机质量不足可改修水侦或 CV 带彩云

### 鲸鱼流（1-A-F-G-H-K）

- 需求：迅鲸/长鲸 + 矢矧改二乙
- 制空：不要
- 索敌：系数=4，≥25
- 分析：AS 带路回避 C 点与 15% G-I 沟；鲸旗舰保护；鲸/矢矧各带瑞云开幕清 DD

### 开幕流（1-C-F-G-H-K）

- 需求：高搭载空母 + 矢矧改二乙 + 水战
- 制空：K 点 126 空优
- 索敌：系数=4，≥36
- 分析：一航战改二放 4 号位抗伤；CL 选阿武隈/夕张/矢矧兼顾开幕雷与二连；6 号位 CLT 保底（三隈改二特更佳）；SS 可打孔电探凑索敌
- 可调：喷气五航/加贺护增加开幕但耗钢；CLT 换 SS、矢矧旗舰可抗撸爷

### 炮击流（1-C-F-G-H-K）

- 需求：伊势改二 + 日进 + 高级瑞云 + 水战
- 制空：K 点 126 空优
- 索敌：系数=4，≥36
- 分析：Boss 拿空优，伊势改二提供 2 轮炮击；3 艘水上舰都配昼战二连观测；日进双 14 改补正高；不推荐警戒阵；T 不利可带彩云

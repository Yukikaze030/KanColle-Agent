# 5-1 南方海域前面

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 地图分析

二期已有固定带路，但制空仍可能丢。能独立完成新三川任务即可算新手期毕业。F 点重兵，偷资源不现实。

## 带路

| 路线 | 编成要点 | 说明 |
|---|---|---|
| B-C-F-J（最短） | 1~2BB + 0~1CVL + 1CL + 2DD + 1CA/CAV/CLT | 敌较弱，只推图推荐；西村/海突可固定带路 |
| B-E-G-J | 水打相关任务用 | 道中较低，瑞云可拿 G 点空确 |
| A-D-E-G-J | 六水战等 | D 点制空高 |

# 3-4 北方海域全域

> 二期 · 改造名须 Data MCP 核实

## 地图信息

道中有不少金撸爷，只有小船流能回避，但 Boss 点敌方 4 大船。F 点强漩涡有概率抽空油；正常攻略应尽量回避 F。捞家具无高性价比配置，不如去 3-3。

## 推荐编成

### 萌新推图 / 划水摸铝（A-C-E-G-J-P）

- 制空：P 点 168 空确。
- 需求：水母。
- 分析：不走漩涡还能捞铝；缺 AV 可去前面图捞一只放旗舰保护；有喂满 CVL 可替 BB 增强开幕。

### 期间限定掉落打捞 / 洗地流（A-C-E-G-J-P）

- 制空：P 点 168 空确。
- 需求：日进；有击坠回避补正的攻击机。
- 分析：双重[战爆CI]提高先手炮击稳定性；日进最大格带索敌≥7 水侦堆接触。

### 敵北方艦隊主力を撃滅せよ！/ 飙船流（A-C-F-J-P）

- 制空：P 点 168 空确。
- 需求：高速+；装甲空母；阿武隈/夕张改二特。
- 分析：全员高速+固定带路；尽量多带电探；长射程空母配战爆CI+彩云。

### 月末战果冲刺 / 水雷魂（D-H-L-J-P）

- 制空：P 点 84 空优。
- 需求：哥特兰改二；夕张改二特；高级水爆；钢板甲驱；若干电探。
- 分析：哥特兰改二为核心下路水雷魂；制空单位外全员电探；S胜率不高不适合捞船；时速30+战果，场均3~4桶。

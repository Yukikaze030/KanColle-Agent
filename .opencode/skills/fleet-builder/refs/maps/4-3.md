# 4-3 リランカ島

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454454084（NGA「带路条件」弹窗）

- 小船对陆倍率测验场。
- 大多数人会在这里第一次见到陆基单位，boss点僚舰很弱，但如果没有针对陆基去配装，会各种打不死
- 各种对陆特效装备的补正T
- 暂时没有发现任何能100%进boss的配置
- 注意A、C点虽然有鱼但会消耗20%油弹
- B、J点可以二连偷油和铝，详情参考下方配置

- 各种攻略路线以及带路：
- 最短路线：
- 2CVL+1CL+3DD
- 推图B胜就可以，不需要带对陆装
- 有9%的概率沟I
- 沟率最低的路线：
- 1CV+1CV系+1CL+3CA系/CLT
- H点的随机沟无论如何都不能避免，所以可以尽量往下路走，L点有100%进boss的带路
- 对陆、对水上输出都很足
- 史实(?)配置路线：
- 2CV+2CA+2DD
- 很多随机路线，目前没有什么优势，仅在任务要求2DD的情况下用比较好

- B、J点可二连偷油和铝

## 推荐编成

### 萌新推图（D-H-N）

- 制空：N点 155空优
- 索敌：无要求
- 需求：非对陆舰爆
- 分析：以boss A胜为目的；昼战敌方剩余≤2船可不进夜战；不带对陆装进夜战也打不死港湾

### 捞油（A-B-G-J，红脸流）

- 制空/索敌：无
- 需求：钢板；警戒阵
- 时速：油+425 弹-960 钢-400 铝+1600
- 分析：不能带CVL（低速走E漩涡）；日进更适合AV位；损管在G点大破进击捞铝不消耗；4格钢板配合警戒阵；约20~25%败场

### 不红脸捞油（A-B-G-J）

- 需求：日进；夕张改二特；阿武隈改二；哥特兰改二
- 每场收益约：油+25 弹-78 钢-17 铝+99
- 分析：不红脸总资源小赚；打两场休息20分钟节奏；夕张/阿武隈外可带钢板；水爆要带对空射击回避补正

## Boss要点

- boss僚舰弱但需对陆装；对陆特效装备是关键

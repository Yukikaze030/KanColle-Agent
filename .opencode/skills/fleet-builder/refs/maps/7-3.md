# 7-3 ペナン島沖

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 地图分析

- 最新实装常规图，两段血条；大量史实带路
- 最短路线周回捞船基本需要神风、羽黑、足柄（没神风先去 P1 捞）
- 期间限定掉落丰富：Pola、Bay(TBF)、Luigi、海防、山风岸波等
- 整体难度不高；周回以重巡（带路）为核心的水雷战队，资源消耗不高（桶除外）
- B 点首次塞进 PT，正常攻略回避

## 制空 / 索敌

- 本图制空 0、索敌 0
- 安全搭载：A-C-E 斩前 1×5 / 斩后 2,1×4；A-C-D-G-P 与 A-C-I-J-P 斩前 15/9/7/7/6，斩后 13/7/7/6/6

## 推荐编成

### P2 稀有船打捞 & 兼顾战果（A-C-D-G-P）

- 需求：神风、羽黑带路；制空/索敌 0
- 兼顾捞船与战果，效率高于 7-1；最上和矢矧最佳（制空 & 开幕雷）
- 前 3 位轮换旗舰保疲劳；神风可红脸；道中 2 战大概率无伤；中破浇桶，神风接近大破再浇

### 提速版（不带飞机）

- 跳过索敌、开幕动画，提高战果效率；代价：损伤与油钢桶略高，铝耗 0

### 稳定版（6 船）

- Boss 点不知道怎么输；高速周回 DD 疲劳不好控制，适合碎片时间偶尔打

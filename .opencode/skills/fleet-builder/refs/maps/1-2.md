# 1-2 南西諸島沖

> 二期 · 改造名须 Data MCP 核实

## 带路条件

- **1CL+4DD（5船）固定 A→E→Boss**；带 6 船会随机沟 B。
- Boss 点 5 船提示 5 船带路。
- 轻型阵容（1CL+若干 DD）通常最短；重编（大量 CV/BB）易绕路。

## 推荐编成

- 路线：1-A-E
- 需求：只带 5 船
- 制空 0 / 索敌 0
- 配装：2 门主炮为主，不打姬级敌舰时一般不带鱼雷；夜战二连是小船主要输出。

# 4-2 カレー洋海域

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 带路条件

| 路线 | 编成要求 | 备注 |
|------|----------|------|
| A-C-L / A-E-G-L / B-D-C-L | 2BB/CV+1CL+1CLT/CA/CAV+2DD | 平衡常规；道中最多3战 |

- 4图相对难度较低；资源点在地图后方
- 出门随机，概率由DD+DE数量决定
- 换成3BB/CV+3DD更高概率走G补给，但道中可能多1战

## 推荐编成

### 萌新推图

- 制空：D点 84空优 / 168空确
- 索敌：无要求
- 需求：7-1通关
- 分析：固定思路 1CL2DD + 有限大船(一般2个) + 其余CLT/CA/CAV；伊势改二长射程舰爆或瑞凤改二前优先带BB

### 月常任务（敵東方 / ろ号 / 空母機動部隊西へ）

- 制空：D点 84空优 / 168空确
- 需求：月常需2空母+2DD；长射程空母
- 分析：矢矧最佳CL人选；道中随机走B点有鱼，瑞凤带对潜≥7舰攻且面板对潜≥65先制对潜

## Boss要点

- D点 84空优 / 168空确
- 道中最多3战，进boss很少出意外

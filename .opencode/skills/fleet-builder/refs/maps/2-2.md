# 2-2 バシー海峡

> 二期 · 改造名须 Data MCP 核实

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454452628（NGA「带路条件」弹窗）

- 目前最新实装的常规图，两段血条，看带路条件的风格和7-2差不多(可能是同时期制作的)，不过增加了大量的史实带路，最短路线周回捞船基本都需要神风、羽黑、足柄三个船的带路。(没有神风先 用神风带路 去P1捞神风)
- 目前有期间限定的丰富掉落，Pola(水战)、Bay(TBF)、Luigi、海防、山风岸波等稀有DD应有尽有
- 地图整体难度不高，周回捞船一般使用以重巡(带路)为核心的水雷战队，资源消耗不高，除了桶外
- B点是常规图第一次塞进PT，正常攻略一般回避这个点，但验证佬们可以上了

- P1常用攻略路线以及带路：
- A-C-E路线：
- (考虑斩后做任务以及捞船，使用P1P2通用的带路)
- 羽黑+3DD
- 平民化的阵容，不需要过多的史实舰，4船的强度足够打P1了
- 羽黑+神风+1DD+1CA系/CL系/AV...
- 多一个神风带路，就可以多带一个开幕船，战损相对来说低一些
- 羽黑+神风+足柄/妙高+1CL系/AV...
- 再多一个足柄/妙高带路，可以替换掉一个脆皮DD，自由位置不能有CA系不过P1本身很简单，加重舰队可能只是徒增消耗
- 1CA+1~2DD
- 不需要史实舰带路，CA位最适合的是Zara或者Pola，带水爆洗地

- P2常用攻略路线以及带路：
- A-C-D-G-P路线：
- 道中2战弱水雷
- 羽黑+足柄+神风+2DD+1CL系/AV...，高速
- 各方面比较均衡的阵容，boss点的斩杀率可接近100%
- CL系/AV建议带一个水战/水爆(安全搭载数见下方)，让CA打昼战二连
- 羽黑+神风+2CA系/CL系/AV...
- 少带两个脆皮DD，但boss点夜战会面对更多的敌人，此时CA也是脆皮了
- 羽黑+神风+2DD+2CA系/CLT/AV...，[高速+]
- 飙船流A，以高速+为代价，换来了……杂技度？
- A-C-I-J-P路线：
- 道中1水雷1鱼
- 羽黑+足柄+神风+1CA系+1DD
- 5船炸鱼流，boss点全体回避较高，弹药消耗较低
- 不过有低概率被J点的鱼射爆
- 羽黑+神风+2DD+1CA系/CL系/AV+1CL，[高速+]
- 飙船流B，CA系+CLT+AV最多2个，剩一个位置有战力的大概就是CL了。
- 想了想好像没啥优势？
- 3DD+3CA系/CL系/AV，[最速]
- 飙船流C，不需要史实带路，需要控制好船速
- A-C-D-G-J-P路线：
- 上两条路线捏到一起
- 羽黑+足柄+神风+1DD+2CA系/CL系/AV...
- 开幕输出最足的阵容，桶耗相对较低
- 但是道中比较长，每一圈花的时间多一点
- 如果上4CA系只能用妙高+高雄带路
- 羽黑+足柄+1CA系+3DD
- 没神风时的可选阵容，用来周回捞船不如先去P1捞个神风
- 羽黑+足柄+妙高+高雄+神风+1DD
- 史实5船带路，没开幕拿不了制空，只能你一炮我一炮的打，损伤会很高，没什么优势

- − 攻击机安全搭载数 ...


出门带路同 2-1；左捞铝，右进 Boss。

| 路线 | 编成 | 说明 |
|------|------|------|
| C-E-F-H-K 最佳 | 1AV+2DE+2CV 系+1CA/CL/SS | 2DE 可捞铝+南西 |
| 1AS+3DD+1AV/CAV+… | 大鲸需 AV/CAV 带路，实用度低 |
| C-E-(F-H)-K | 1AV+2DD+3CA/CL | 无 2DE 捞船；司等 80+ 可能双撸爷 |

| 左路捞铝 | 3CV 系 或 1AO+5DD/CL 全大发 | 后期高效低耗 |

千姐妹务必各留 AV 形态；大鲸 4-4 可捞。

## 制空 / 索敌

K（Boss）司等≤49：72 确；≥50：18 均 / 41 优 / 81 确。索敌 0。安全搭载 C-E-(F-H)-K：4/3/2/2/2；C-E-G-(H)-K：6/5/3/3/3。

## 推荐编成

- **萌新** `1-C-E-(G-H)-K`：AV+大船；AV 放旗舰；大船多则 G 撸爷概率高
- **南西** `1-C-E-F-H-K`：1AV+2DE+低耗 CVL+CL；一改大鹰/神鹰不能带彩云；DE 未改造修得快；轮型红撸爷 3 固定击坠优先回避飞机；掉落不如 2-3
- **ろ号作戦** `1-C-B-A`：3CV 系+大发/桶；CVL 搭载≤17 不喷铝
- **捞铝** `1-C-B-A`：AO 带路（宗谷>神威；山汐丸可当 CVL；速吸别用）+低耗 CVL（云鹰）+大发 DD；时速油−800 弹−800 铝+1700；拉烟红脸运≥26+1 大烟；警戒阵全员大发，SS 不合适

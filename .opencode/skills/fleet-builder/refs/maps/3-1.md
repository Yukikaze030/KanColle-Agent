# 3-1 モーレイ海

> 二期 · 改造名须 Data MCP 核实

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454453286（NGA「带路条件」弹窗）

- − 地图简介 ...
- 两个出发点，两条风格迥异、难度差别巨大的攻略路线，汇聚到1~2水上舰+3~5陆基混合的boss点，总之建议先到这里T补充一些关于陆基的知识，做好万全的准备再推这张图。
- 火力阈值提升的当前版本，对陆图的难度大幅降低，基本不需要特意压低提督等级了，除非一件对陆装备也不想做。想要比较轻松地通关6-4，建议练对陆船(满潮、霞、伊势改二、夕张改二特、最上改二特)、清理奖励对陆装备的任务(大发、内火、迫击炮)、改修对陆装备(大发→战车、内火)、日常开发陆航(4陆攻)、清理开放陆航以及获取设营队的任务。
- 与5-2以及活动图不同，6-4(和6-5)的空袭点消耗4%油8%弹，非最短路线很容易导致boss点输出大幅下降。
- 各种攻略路线以及带路：
- 左路：
- C点有双撸爷坐镇，不能带空母，我方舰队很难先手阻止撸爷的炮击劝退，务必提前做好舰队的配置准备以及提督的心理准备。
- B-D-C-F-N路线：
- 需要全队高速才能走，一般称作高速流路线
- 需要谁腾出一个格子带水战
- CL旗舰+3DD+1~2CA系/CL系/AV等+最多1BB系，全队高速
- 传统常规高速流，无论你想不想打立体攻击，BB位都推荐用伊势
- 4DD+1~2CA系/CL系/AV等+最多1BB系，全队高速
- 旗舰不限，某些限定非CL旗舰的任务，又没有秋津洲的时候可选
- CL旗舰+3DD+长门改二+陆奥改二
- 长陆改二的特殊带路之一，比常规高速流多了一个BB，无论是对水面还是对陆输出都很扎实
- 4DD+长门改二+陆奥改二
- 长陆改二的特殊带路之1.5，可兼容胸热，不过如果对陆装足够且陆航炸boss，胸热只是徒增不稳定性
- A-D-C-F-N路线：
- 出门的水雷点比高速流难很多，不带BB基本没法打，带BB需要秋津洲带路，不限速，俗称低速流路线
- 秋津洲可以背水战所以制空比高速流好拿很多
- 秋津洲+2DD+1CL/CAV+1BB系+1CA系/CL系/AV等
- 传统常规低速流，对水上与对陆输出比较难以平衡，这个版本有了双舰爆、M4A1等强力对陆装备的情况下比以前好打很多
- 秋津洲+2DD+1CL/CAV+长门改二+陆奥改二
- 长陆改二的特殊带路之二，很适合胸热的发挥
- 右路：
- 右路即使最短路线也有金so、wo改、主任领衔的豪华阵容，历战甲鱼可以打打玩，正常完全不推荐走这条路。
- M-K-J-N路线：
- 1LHA+1CL+2DD+1BB系+1CV系
- 高难度路线1号
- M-K-J-L-I-N路线：
- 2DD+1BB系+2CV系+1CA系/CL系...
- 高难度路线2号
- M-K-H-J-I-N路线：
- 长门改二+陆奥改二+1CL+2DD+1CV系
- 高难度路线3号，长陆改二的特殊带路之三

- − 关于陆航 ...
- 关于如何操作请查阅wiki
- 开放6图陆航需要完成F43任务 "中部海域'基地航空隊'展開！"，而每开启一队需要消耗一个"設営隊"。在开启6图陆航前，"設営隊"可以通过B80[飛行場設営の準備を実施せよ！]、B81[夜間突入！敵上陸部隊を叩け！]、Cy6['改装特務空母'任務部隊演習！]、F106[鎮守府'大掃除'祭り！](最简单)几个任务，以及氪金获得。6-4可出击一队陆航，6-5可以出击两队守家一队，7-4可以出击一队。任务给的"設営隊"足够用，普通玩家不必氪金。多余"設営隊"可以投入到强化整备中，最明显的提升是加快了飞机的疲劳恢复速度。6图/7图/活动图分开强化，建议在开完6图2队、7图1队后，优先提升活动图强化等级。
- 陆航输出是6-4非常重要的一环，在开启陆航前打6-4是不明智的选择。虽然现在boss点基本不需要陆航输出了，但在提高道中通过率方面的作用还是非常大。
- 陆航对水上舰攻击力计算雷装(0雷装攻击机则计算爆装)，对陆基攻击力计算爆装(0爆装攻击机只能打出擦弹伤害)。
- 具体攻击力公式可以去各种wiki查询，陆攻的攻击力比舰攻舰爆高不少。
- 面板命中会大幅提高命中率，在雷装/爆装差不多的情况下优先带命中高的
- 建议打6-4之前先凑齐4架一式或更强的陆攻，如果陆航炸道中，也可以用高命中舰载机(村田、友永等)代替
- 陆航中携带任意喷气机可以无视航程直达boss点，这是6-4独有的特性，不适用于其它地图。(不过不能直达其它道中点)
- 目前(2021年5月)各wiki的陆航对陆公式存在问题，仅供对比一下各飞机大概的强弱，根据公式做定量的伤害计算是不准确的。尤其是喷气机，实际没有对陆补正。
- 陆航翻牌到休息会降低铝的自然回复速度，吃低保的同学需要注意

- − 关于敌舰 ...
- 左路出门的水雷点：
- 高速流只有5船，非常弱
- 低速流强了不止一个档次，必须要带BB+若干打得动金雷巡的船，否则大概率劝退
- D、F的空袭：
- 不算很强的空袭，但完全不管也会爆炸。
- 制空配到优势以上可以不带对空CI，否则建议配个对空CI。对空CI优先发动率，因为敌方是4格搭载不高的陆爆，较弱的对空CI也能降低不少损伤。
- C点撸爷：
- 6号位混有一个轻母，至少要拿空均，否则很难打
- 撸爷一炮一个小朋友，对陆输出不足的时候陆航必须去炸boss，这里就成了最精污的地方
- 火力阈值提高后boss点不缺输出，一般陆航建议都放到C点
- BB没有必要为了这里特意带水侦打二连，高火力BB配合徹甲弹就能较高概率一炮击杀开幕洗过的撸爷
- 适当带开幕雷也是不错的选择，前提是对陆输出足够
- boss点的离岛：
- 非常硬，体现在血量、装甲高，以及部分对陆装补正低下(比如三式弹)
- 建议陆航炸道中的情况下，队伍中配置3个对离岛夜战二连火力达到阈值(360)的单位，一拳可以算半个
- 陆航炸boss则可以适当降低
- boss点的集积地(DJ)：
- 薄皮大馅，是首要迫害对象。
- 大多数对陆装都有阈值后补正(三式弹除外)，但只带单件对陆装的话会被她吸收大量伤害
- 建议陆航炸道中的情况下，队伍中有3个一拳配装单位，陆航炸boss则可以降低到1~2个，太少会被DJ吸收不少炮击次数
- 如果想同时兼顾夜战对离岛的稳定输出，使用能装备双炮+战车+内火的船是比较好的选择。
- boss点的炮台：
- 对空很高，导致老司机大量跳海的元凶
- 很微妙的血量和装甲，过去昼战比较难一炮击杀，现在阈值提升后秒杀概率高了不少。
- 建议全员都有能打炮台的输出(比如对空DD也带个火箭弹)，尽量昼战解决炮台，拖到夜战炮台会吸收本应对付离岛的火力点，而且其本身夜战二连输出恐怖
- boss点的水上舰：
- 金皮补给堪称boss点最硬的一艘船，会吸收大量对陆火力，小船昼战几乎拿它没办法
- 想解决它可以靠长陆胸热/复数开幕雷/陆航
- 选用开幕雷的场合需要衡量一下对陆输出是否足够
- 右路道中：
- 豪华的活动甲难度阵容

- − 关于舰队成员的选择 ...
- 首先无视高难度的右路，这里只说左路。
- BB系：
- 正常左路只能带一个BB，但长门改二+陆奥改二的CP可以突破这一限制，由于长陆本身属性不错，再加上可携带对6-4陆基补正很高的大发系装备，围绕长陆可以组出很多种可行的攻略方案。
- 由于双舰爆对离岛和炮台的补正爆表，再加上携带舰战辅助制空的特性，伊势是不能打特殊攻击的BB中最适合的人选。日向由于搭载偏低，不太适合敌方高强度对空的6-4
- 纳尔逊可以带对陆小船摸陆基，使得她是不能携带6-4对陆特效装备的BB中的首选，不过由于必须要放旗舰位，高速流只能带一个水战巡洋舰+4DD，全程输出不足；低速流又不能有效保护脆皮的秋津洲，当前版本较为尴尬。
- 大和属性非常扎实，改二形态是高速流最稳的BB人选。改二重形态也很适合低速流，不过无法改变低速流不好处理金CLT的情况，出门的劝退率都快赶上高速流整体劝退率+刁民率了。
- 其他BB在6-4就比较平庸了，不过任意高速BB配矢矧+最上走高速流都是可行的。
- CA系：
- 三式弹对6-4各陆基的效果都不好，所以一般不考虑让CA出场
- CAV在低速流中有带路，并且可携带补正比三式弹高一些的火箭弹(也可与三式弹混搭)，相对于CA会更适合一些。
- 熊玲改二可在洞里装副炮，兼顾辅助制空与夜战对离岛的高强度输出，比其他CAV的配装更灵活一些。但要注意巡洋位如果不兼顾昼战对水上舰输出的话，很可能导致连续的劝退。
- 而6-4最强最万能的CA系就是最上改二特了，基本别人能做的不能做的她都能做。
- CL系：
- 万能的矢矧是首选，除了专业对空外啥都能做，并且做的都比别人好。
- 夕张改二特除了不能背水战，对于其它船的配装略有限制外，现在还算能打。别忘了本身是低速，走高速流要打孔提速
- 哥特兰/能代改二可以携带双主炮+水侦/水爆+登陆艇/内火艇打昼战二连，在能拿到boss空优的阵容中有不错的发挥。
- 大淀可以携带双火箭弹+对空电探+高角炮+打孔高角炮兼顾对空CI，也许比较适合偏爱万能兼容杂技风格的提督
- 其他4格CL无法兼顾昼战二连与夜战对离岛摸到火力阈值的二连，双炮双火箭弹对DJ的输出差一些，双炮水侦火箭弹夜战对离岛输出不高，总的来说不如上述几位。
- 由良...就当她是时代的眼泪吧，在其它图背水战还是可以的
- DD：
- 6-4对DD的要求有：昼战一拳对DJ、夜战二连对离岛、道中对空三点。
- 当前版本不缺对陆输出，DD的生存能力是影响每次出击S胜率的关键点。可携带钢板的响爷改二、雪风改二、弗莱彻改二基本算是一拳、二连、对空三个位置的首选。
- 其它一拳DD中。不吃图纸且高火力的的满潮和霞是性价比很高的选择
- 二连DD基本就是高火力且可携带登陆艇/内火艇的比较强，如果有两个火箭弹的话，塔什干也是非常强力的人选
- 对空DD除了弗莱彻外，当然是秋月级比较好，只需要双炮就能发动对空CI，剩下一个格子可以带一个火箭弹打炮台

- − 关于对陆基敌人的配装 ...
- 这里是详细补正公式T
- 对集积地(DJ)：
- 通常使用"一拳"套装来昼战一炮击杀。
- 标准"一拳"套装：
- [大発動艇(八九式中戦車&陸戦隊)](俗称战车)+[特二式内火艇](俗称内火)+[WG42(Wurfgerät 42)](俗称WG)。(三件装备的重要程度依次降低)
- 其实算是一期遗留下来的比较过时的一种配装，二期战车改修对DJ补正的增加到了3处，也就是每敲一锤子可以提升3个2%的火力，在改修够高的情况下，完全可以抛弃WG换成电探来提高命中。
- 因此对于6-4来说，高配"一拳"套装是[大発動艇(八九式中戦車&陸戦隊)+max]+[特二式内火艇+max]
- 6-4的DJ在DD满弹药进boss时需要730的火力可以稳定击杀，其他舰种弹药可能会不满，需要的火力会略有提升。实战配到中破返航730还是大破T不利730就看各位的装备质量了。
- 在活动图DJ有若干皮糙肉厚的进化形态，此时可能需要带第三件对陆装
- 有些时候高级对陆装不足，或某船带不了某装备，就需要进行下位替换。
- 战车不足：
- 下位替换是各种登陆艇。在计算火力时由于一拳类型配装的阈值前火力都大幅度超出阈值，所以可以只计算阈值后的倍率来确定谁强谁弱。要注意的是，[特大発動艇+戦車第11連隊]阈值后只有登陆艇的通用类别补正，并且本身无法改修，算是比敲一锤子的白板大发更下位的选择。
- 无法携带登陆艇的时候，也可用更下位的火箭弹，或最下位的迫击炮替换
- 内火不足：
- 通常用火箭弹，或迫击炮替换
- 也可用登陆艇比如第二个[大発動艇(八九式中戦車&陸戦隊)]、[特大発動艇]、[M4A1 DD]替换，但要注意，登陆艇的改修补正计算的是所有登陆艇类装备的平均值，如果用改修值比第一个[大発動艇(八九式中戦車&陸戦隊)]还要低的登陆艇替换，有可能反而会降低火力
- 火箭弹不足：
- 通常用下位的迫击炮替换
- 值得注意的是，名字相同的火箭弹和迫击炮，第二件装备的补正比第一件高，因此大多数情况，同名的装备一起装备会比不同名装备混搭的火力高。

- +(双战车除外)
- ×1+×1

- 名字相同的×3
- 多个一拳配装的输出尽量平均一些，比如手里有内火+6、战车+6、对地喷进炮、若干大发+6、若干迫击炮，要配两个一拳DD，比起凑内火+战车+对地喷进炮的标准一拳，其中一个DD带内火+大发+对地喷进炮，另一个DD带战车+迫击炮+迫击炮的效果好一些。
- 对离岛：
- 昼战只有靠big7的特殊攻击才能一炮击杀，这里就不是对陆配装的讨论范畴了T
- 长门T不利一炮打出过480伤害直接秒杀
- 夜战需要配二连攻击才能对其稳定输出，也就是要带两门炮。
- 对于DD来说，第三件装备选[M4A1 DD]>[特大発動艇+戦車第11連隊](俗称士魂队)>高改修的[特二式内火艇]，当然格子多的塔什干带两个[火箭弹](两个名字相同的补正高)也是不错的选择。由于DD基础火力不高，双炮+其它单件对陆装输出就不太行了，遇到这种情况建议随便抓三件剩下的对陆装凑个一拳效果更好一些。
- 不过一拳配装只有单发而且命中率不高，对离岛来说不是很稳定，但如果是改修够高可以配一个电探提高命中。在没有顶级对陆装的情况下，一拳配装中破时的输出可能反而比二连还高
- 对于CL来说，4格船以及孔里能装副炮的由良都是不错的选择，其中夕张改二特、由良更可以兼顾高配的对DJ"一拳"配装
- 对于CA来说，三式弹对离岛只有1.75倍，单三式弹是一个很差的选择。一般使用CAV携带三式弹+火箭弹，或两枚火箭弹比较好。双火箭弹对DJ的补正高一些，不过DJ一般由一拳小船来解决。
- 对于BB来说，本身火力高，单三式弹打离岛没多大问题。
- 由于第二个舰爆对离岛补正很高，双舰爆的伊势级改二是少有的中破对离岛火力也能摸到阈值的BB
- 对炮台：
- 以前昼战180火力阈值的版本很难一击满血击杀，想提高击杀率需要阈值后补正，而阈值后补正的来源主要有3个
- 1、big7特殊攻击
- 随便摸一下就打掉了
- 2、暴击
- 空母以外的船无法主动堆暴击率，而空母面对炮台时老司机大量跳海，根本堆不出暴击率
- 3、观测射击
- 需要拿空优，伊势以外的流派很难配出多个观测配装，并且每多带一架战斗机/侦察机，就会极大削弱对离岛以及DJ的输出

- 而现在昼战220火力阈值的版本满血击杀率则高很多，实战一般不会围绕它来优化配装，让对空打杂的DD带一个火箭弹即可

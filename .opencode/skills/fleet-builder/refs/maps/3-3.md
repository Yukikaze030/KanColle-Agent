# 3-3 アルフォンシーノ方面

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454453396（NGA「带路条件」弹窗）

- 做北方周常难度最低的海域
- 无法回避漩涡所以无论做什么都要尽量多些船带电探，F点有概率踩到强漩涡
- 下路是目前捞家具币效率最高的地方，不过没有发现固定的带路，可以参考下方的详细配置

- 各种攻略路线以及带路：
- A-C-G-M路线：
- 1CV+1CVL/BB+2CLT/CA/CAV+2DD
- 正常推图的唯一推荐路线，需要正航或装母带路
- 2DD各带一个电探，CA或CLT也可以考虑带个电探，相等于增加全队的回避率


| 路线 | 编成要求 | 备注 |
|------|----------|------|
| A-C-G-M | 1CV+1CVL/BB+2CLT/CA/CAV+2DD | 正常推图唯一推荐；需正航或装母带路 |
| A-B-D / A-B-F-H | 2DD + 2CVL + 1~2SS 等 | 捞家具币；B点后随机 |

- 无法回避漩涡，尽量多带电探；F点有概率强漩涡
- 2DD各带电探；CA/CLT也可带电探提高全队回避
- 北方周常难度最低海域

## 推荐编成

### 萌新推图（A-C-G-M）

- 制空：G点 78空优 / 156空确
- 索敌：无要求
- 需求：电探

### 北方周常

- 路线：A-C-G-M
- 制空：G点 156空确
- 需求：季常任务需1CL；长射程空母；电探
- 分析：BB可换CVL加强开幕；CA带电探降油耗；CV带彩云防T不利开幕雷刮痧

### 捞家具

- 路线：A-B-D / A-B-F-H
- 需求：钢板
- 分析：固定走B后随机；DD带路+红脸挡枪；钢不够可 2~3CVL+2DD+1~2SS 轮换

## Boss要点

- 全程空确；漩涡点多带电探降低油耗与回避debuff
- CLT雷装拉满开幕雷击杀敌方BBCV概率不低
- 接触开始率：10索敌彩云≥6搭载格，或8索敌彩云≥9搭载格可达100%

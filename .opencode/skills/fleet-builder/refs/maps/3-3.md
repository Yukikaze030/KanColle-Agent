# 3-3 アルフォンシーノ方面

> 二期 · 改造名须 Data MCP 核实

## 地图信息

做北方周常难度最低的海域。无法回避漩涡，尽量多带电探（F 点有概率强漩涡）。下路是捞家具币效率最高的地方。

## 带路条件

> 来源：https://bbs.nga.cn/read.php?pid=454453396（NGA「带路条件」弹窗）

| 路线 | 编成要求 | 备注 |
|------|----------|------|
| A-C-G-M（推荐） | 1CV+1CVL/BB+2CLT/CA/CAV+2DD | 正常推图唯一推荐；需正航或装母带路 |
| A-B-D / A-B-F-H | 2DD + 2CVL + 1~2SS 等 | 捞家具币；B 点后随机 |

- 2DD 各带电探；CA/CLT 也可带电探提高全队回避。

## 制空 / 索敌

- G 点：78 优势 / 156 确保。
- 索敌：无要求。
- 接触开始率：10 索敌彩云≥6 搭载格，或 8 索敌彩云≥9 搭载格可达 100%。

## 推荐编成

### 萌新推图（A-C-G-M）

- 制空：G 点 78 空优 / 156 空确。
- 需求：电探。
- 分析：BB 可换 CVL 加强开幕；CA 带电探降油耗。

### 北方周常（A-C-G-M）

- 制空：G 点 156 空确。
- 需求：季常任务需 1CL；长射程空母；电探。
- 分析：CV 带彩云防 T 不利开幕雷刮痧；CLT 雷装拉满开幕雷击杀概率不低。

### 捞家具（A-B-D / A-B-F-H）

- 需求：钢板。
- 分析：固定走 B 后随机；DD 带路+红脸挡枪；钢不够可 2~3CVL+2DD+1~2SS 轮换。

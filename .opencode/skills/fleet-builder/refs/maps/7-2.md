# 7-2 タウイタウイ泊地沖

> 梦美常规图带路 · 二期 · 改造名须 Data MCP 核实

## 地图分析

- 双血条，不同阶段带路有微妙变化；血条每月回复，击破无奖励，不影响后续开图
- P1 斩后无补给（司令部低时也无）；P2 斩后无红泡芙
- Boss 掉落尚可，P1/P2 均可捕捞海防

## 带路

| 阶段 | 路线 | 编成要求 | 说明 |
|------|------|----------|------|
| P1 | C-E-G | 2CVL+3DE | CVL 打水上、DE 打水下；DE 不足可 1CVL+3DD/DE |
| P2 | B-C-D-I-M | DD≥2 且 CV≤1 且 BB系+CV系≤3，全队高速 | 直接走 C 只能 5 船带 3DE 打不了 boss；tsu 多可罚站空母省铝 |

## 制空 / 索敌

| 点 | 均势 | 优势 | 确保 |
|----|-----:|-----:|-----:|
| H | 176 | 395 | 789 |
| M（斩前） | 160 | 359 | 717 |
| M（斩后） | 118 | 266 | 531 |

- P1 制空 0
- P2 制空：司令部 98 以下或斩后 266 空优；99 以上且斩前 359 空优
- P2 索敌：系数=4，≥69
- 安全搭载：C-E-G 均为 1；B-C-D-I-M 空优 43/23/19/15/13

## 推荐编成

### 萌新推图 [P1]（C-E-G）

- 需求：对潜装备
- DE 需在 7-2 打捞；敌方水陆混合 3 潜艇，前期需 3DD 全配反潜；有先反 DD 时另一 DD 可双炮打夜战

### 萌新推图 [P2]（B-C-D-I-M）

- 需求：练度别太低；制空/索敌见上表
- 敌方对空高，小格易被打空，CVL 可罚站；前期捞船会让司令部等级快速增长

### 泊地周辺海域の安全確保 [P1]（C-E-G）

- 需求：海防舰；护卫空母；制空 0
- 一路上无敌方对空击坠，CVE 带最强飞机洗过去即可

### 泊地周辺海域の安全確保 [P2]（B-C-D-I-M）

- 需求：装甲空母；制空/索敌同 P2
- 无法走最短路线；双空母各一舰攻不如给 CV 配 CI；对空 CI 意思一下，重点在输出与道中通过率

### 期间限定掉落打捞（B-C-D-I-M）

- 需求：5 格空母；实力越强消耗越低
- 制空：boss 斩后 531 空确；索敌：系数=4，≥69
- 空确降铝并避免渊田队被打空；不带 BB 系降油弹且 boss 少一轮炮击
- 加贺非护形态可用吃喝戊放旗舰打夜战；制空不够可矢矧/最上换高速伊势带舰战

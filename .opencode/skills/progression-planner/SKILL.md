# Progression Planner Skill

**时期：练舰/改造价值基于二期环境。**

## 触发

练谁 / 改造目标 / 账号发展 / 资源规划 / 短板。

## 工作流

1. **玩家舰娘与等级**
   - Poi `poi_query_ships`（可按 damage 过滤排除大破）
2. **改造链（必须查 Data，禁止记忆）**
   - Data `kc_ship_remodel` / `kc_search`：对**每一艘**写进「立刻改造 / 练到改二」的船单独核实
   - 链上**没有**的形态（如雲龍改二、葛城改二、阿賀野改二）**不得**写成目标
   - 找出「接近下一改」的候选（差级小、价值高）；无下一改则只练到当前形态或活动线
3. **价值**
   - kcwiki-researcher 查当前版本重要舰娘（活动刚需、炮航巡、特殊装备搭载）
4. **资源**
   - Poi `poi_get_overview` / `poi_get_inventory`

## 输出（必须明确排序）

```
第一优先：舰名（当前 Lv → 目标 Lv，理由）
第二优先：…
第三优先：…
暂时不用练：…
资源注意：桶/开发/改修是否卡脖子
```

## 硬规则

- 禁止只说「各有优缺点」
- 改造等级/是否存在改二以 Data MCP 为准，不靠记忆；未查询不得断言改造形态
- 大破/入渠中不作为近期练级首选
- 短板要结合玩家已有高等级船，避免推荐重复功能船
- 短板要结合玩家已有高等级船，避免推荐重复功能船

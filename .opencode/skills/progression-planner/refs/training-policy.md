# 常见舰娘培养候选

原帖目标是准备至少两套联合舰队，以常规图可获取、少吃图纸的舰娘为主。达到目标改造后优先喂满火力、雷装、装甲；难出击的船用演习补经验。以下为原帖摘要，不替代 Data 对改造形态和等级的核实。

## 基础骨架

| 类别 | 优先候选 | 原帖给出的培养目标与用途摘要 |
|---|---|---|
| 高速战舰 | 金刚级四舰 | 一改 Lv25；活动联合舰队需要轮换，性价比优先雾岛 |
| 特殊攻击战舰 | 长门 | 尽量到 Lv88；高难海域特殊攻击核心，捞不到时陆奥先作搭档 |
| 航空战舰 | 伊势 | 尽量到 Lv88；改造后五格并可带舰战，平时也常用，但消耗高 |
| 正规空母 | 赤城、加贺 | 一改 Lv30，前期长期可用 |
| 舰载机来源 | 苍龙 Lv78、飞龙 Lv77 | 改造本体之外，重点是相关舰载机；之后可进支援队 |
| 装甲空母 | 翔鹤 Lv88、瑞鹤 Lv90 | 面向活动高难培养；需要图纸和甲板 |
| 轻空母 | 瑞凤 Lv80；千岁/千代田 Lv50 | 瑞凤为高速长射程护卫空母；千岁田易得、门槛低，另留水母形态有用 |
| 航巡/重巡 | 最上、摩耶 Lv75、妙高 Lv70 | 最上一改即高性价比航巡，后续重点培养；摩耶负责专业对空；妙高可作夜战输出 |
| 雷巡 | 北上、大井 Lv50 | 决战及周回核心；不影响带路时联合二队优先 |
| 轻巡 | 夕张 Lv86、川内 Lv60、五十铃 Lv50 | 夕张是开幕雷/对陆候选；川内主要提供夜战装备；五十铃解决前期先制反潜 |
| 夜战驱逐 | 雪风一改、时雨 Lv60、绫波 Lv70、霞 Lv75 | 雪风一改即可应对较低难度；时雨易培养；霞兼夜战、对陆、运输；绫波慢慢练 |
| 对空/对潜驱逐 | 初月/秋月一改、Johnston一改、浦风丁改 | 专业对空或无条件先制反潜；浦风兼对潜、对陆和水雷战 |
| 对陆/运输驱逐 | 霞、满潮 Lv77、皋月 Lv75、三日月一改 | 建立登陆艇运输与对陆轮换；皋月兼大发改修和远征 |
| 设施舰 | 明石 Lv35 | 一改提高改修成功率并扩展泊地修理能力 |

## 选择规则

- 先补“完全没有”的功能，再扩充第二套联合舰队，不按表中出现顺序机械排序。
- 已持有水雷熟练见张员与 D 型炮、要发挥夜战驱逐时，将对应夜战驱逐的阶段目标提高到 Lv80。
- 高成本最终形态交给图纸策略；本表中的“一改可用”常常比立即投入稀缺道具更优。
- 原帖的打捞状态可能随版本变化，不用它判断当前是否可获取。

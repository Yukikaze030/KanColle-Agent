# 全舰娘性能简述：查询规则

原帖明确将用途分为“捞到后判断是否好用、船位紧张时是否保留、了解舰娘性能”；图纸分配与培养先后分别应参考图纸推荐和常见船培养推荐。因此本 ref 不维护另一份全舰排名。

## 使用方式

1. 先由 `training-policy.md` 或 `blueprint-policy.md` 产生最多数个候选。
2. 需要解释定位、判断同功能重复或比较同舰种时，再查本来源中这些候选的段落。
3. 获取难度、社区点评和角色定位可以引用；属性、装备适配、改造形态、等级与消耗必须回到 Data。
4. 原帖是持续更新的多页长文；活动倍卡与当前获取状态属于时效信息，交 researcher 复核。

## 决策抽取字段

每个候选只保留：`舰种/关键形态`、`核心功能`、`相对同类优势`、`主要限制`、`适合账号阶段`、`获取难度（如仍有决策价值）`。不要复制角色介绍、历史背景或整段原文。

## 高优先候选性能摘要

| 候选 | 核心价值 | 限制与培养时机 |
|---|---|---|
| 长门 | 高性价比战舰特殊攻击，可带水战并兼顾对陆 | 入手即练；相较陆奥通常优先，活动或高难图前改造价值高 |
| 伊势 | 五格航空战舰，可用舰战缓解制空；相关任务提供长射程舰爆 | 有能力取得甲板后升至最高优先组，通常竞争第一块甲板 |
| 最上 | 一改很早即可成为实用航巡；最终形态兼开幕雷、对陆和制空辅助 | 一改可先建立廉价航巡轮换；高阶改造需图纸、详报和航空资材 |
| 矢矧 | 高火雷、四格，最终形态兼水战、甲标和对陆 | 持有即重点培养；成本不止图纸，基础运也影响决战培养成本 |
| 大和 | 五格、高面板，双形态适应高速或航空战舰场景，特殊攻击上限高 | 图纸和搭档成本很高；先确认可用伴随舰再投入 |
| 武藏 | 常规战舰面板顶级，可带水战，常作大和特殊攻击伴随舰 | 日常消耗高且不能单独发动该特殊攻击；通常已有大和后培养 |
| 加贺 | 一改即强；高阶五格形态覆盖高搭载、夜战和护卫用途，任务可补火箭机 | 消耗两图、甲板、详报及航空资材；火箭机不足时优先级上升 |
| 翔鹤/瑞鹤 | 装甲空母中破可炮击，翔鹤火力略高、瑞鹤搭载分布略优 | 通常在伊势之后竞争甲板；瑞鹤还关联岩本任务链 |
| 夕张 | 最终常用形态可开幕雷、对陆，装备栏多且基础运较友好 | 低速通常需要补强增设配合提速；没有矢矧时优先级更高 |
| 长波 | 中高火雷，季常任务可稳定取得战斗详报 | 凑齐任务所需僚舰后尽早改造，以提前开始详报回收 |
| 初月 | 高阶形态四格、强对空，可兼顾对潜和炮击；任务及改修提供强化秋月炮 | 需要图纸、详报和兵装资材；需要额外装备格或提高防空生存时改 |
| 深雪 | 特定主炮加成高、可对陆；任务提供常规可得的大型烟幕 | 准备挑战高难海域、需要稳定烟幕前培养，不能只按面板评价 |
| 日向 | 五格并偏向先制反潜 | 通用性和搭载通常不如伊势；完成更高价值甲板船后再考虑 |
| 龙凤 | 高阶形态可成为独特夜战轻空母 | 从大鲸转轻空母不可逆且中间形态弱；已有夜战飞机后价值上升 |
| 鸟海 | 重巡火雷突出，任务链和季常提供长期收益 | 缺少特殊战斗功能；排在能引起舰队质变的图纸船之后 |
| 由良 | 水战、甲标、登陆艇/内火艇与补强副炮组合，相关任务提供高价值水侦/夜侦 | 前中期质变有限，准备更高难度内容时提升优先级 |
| 天津风 | 一改提供提速装备；高阶形态战斗性能、对陆和单锅高速+兼备 | 船位允许时保留继续培养；水雷见张相关任务会显著提高投资价值 |
| 时雨 | 低门槛改二、高运，前期即可承担夜战决战 | 更高阶形态很强但成本巨大；先用改二，资源富余再继续 |
| 三隈 | 一改提供航巡轮换和三号炮；最终水母形态在同舰种中生存突出 | 普通改二过渡价值低；没有日进或准备喂运时才提高图纸优先级 |
| Fletcher | 无条件先制反潜并擅长对空，任务可取得高对潜装备 | 获取难；改造链中间形态关联任务，不能直接跳过核查 |
| 雪风 | 一改门槛低且高运高夜战能力，低难活动已足够 | 丹阳是中间取向形态；高阶改造成本很高，基础功能船齐全后再投入 |

## 与另两篇来源的冲突处理

- 具体图纸投资先采用更新较新的 `blueprint-policy.md`。
- 无图纸基础舰队建设先采用 `training-policy.md`。
- 本帖用于补充“为什么”和“与现有舰是否重复”；若观点不一致，标明来源更新时间并结合玩家当前缺口裁决。

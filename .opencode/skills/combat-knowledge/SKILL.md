# Combat Knowledge Skill

只保存**稳定概念**、查询流程、重要术语。精确公式与活动特例 → kcwiki-researcher。

## 机制速查（概念层）

| 术语 | 要点 |
|------|------|
| 制空 | 舰战/陆攻熟练与机型决定制空权；空确/空优影响昼战与炮击 |
| 索敌 | 影响能否进 Boss；与雷达、舰载机、电探相关 |
| 昼战 | 炮击战开幕后；弹着观测、cut-in 依赖火力/搭载 |
| 夜战 | 夜战 cut-in / 连击；探照灯、照明弹、夜战飞机 |
| 触接 | 提高命中与暴击；水上观测机/舰侦相关 |
| 弹着 | 观测射击：主副/主主/主彻 等条件 |
| 特殊攻击 | 三式弹对陆、对空 CI、特殊舰 cut-in（大和/长门/扶桑等） |
| 对潜 | 水听/爆雷/爆投；空母机对潜与先制对潜条件 |
| 陆航 | 陆攻/陆战转场；航程、熟练、机场设置 |
| 支援 | 远征支援与决战支援触发条件 |
| 联合舰队 | 一队二队编成限制；空母机动/水上打击 |

## 查询流程

用户问「为什么没 cut-in / 怎么堆制空」：

1. 若可结构化：Data `kc_get` 装备数值 + `kc_equipment_rules`
2. 精确机制：kcwiki-researcher 查术语页
3. 结合玩家编成（Poi）给出可执行建议

## 硬规则

- 不要把几十页公式塞进回答
- 活动特例必须 Wiki
- 数值以 Data MCP / Wiki 为准

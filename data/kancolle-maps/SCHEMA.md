# 统一标题规范（maps/*.md）

MCP / Agent 检索用固定二级标题，便于按海域抽取元素。

## Frontmatter（必填）

```yaml
era: "2"
source: "<pid URL>"
updated: "YYYY-MM-DD"
summary: "常规图 <id> <日文名>（精简）"
map: "<id>"
fetch_status: "slimmed"
slimmed: true
```

## 二级标题（固定顺序）

| 标题 | 必须 | 内容 |
|------|------|------|
| `# <id> <日文名>` | 是 | 一级标题 |
| `## 地图信息` | 是 | 一句话定位 / 血条 / 特殊机制；无则写「—」 |
| `## 带路条件` | 是 | 路线、分歧条件、索敌/装备带路（来自 NGA 弹窗） |
| `## 敌方配置` | 是 | 各点敌舰、制空均势/优势/确保（压缩表） |
| `## 制空 / 索敌` | 是 | 推荐制空与索敌阈值；无则「—」 |
| `## 推荐编成` | 是 | 主流编成 / 流派 |
| `## 任务配置` | 是 | 出击任务推荐（可指向 quest-sortie-configs） |
| `## 备注` | 否 | 改造须 Data MCP 核实等 |

禁止保留：`带路`（旧名）、`相关任务`、`出击任务` 等别名标题——统一为上表。

## 敌方配置压缩格式

```markdown
| 点 | 敌舰（压缩） | 制空均势 | 优势 | 确保 |
|----|--------------|----------|------|------|
| B | 重巡リ級flag, 駆逐ロ後×4 | — | — | — |
```

敌名可用缩写：`flag`=flagship, `後`=後期型, `空母ヲ` 等；保留关键 CV/BB/LHA。
